Multi-Source ETL Pipeline
A Python ETL project that extracts, transforms, and loads data from multiple sources into PostgreSQL.

Current Features
Extract product data from a REST API
Transform data using Pandas
Remove unnecessary columns
Rename columns for business-friendly naming
Add ETL load timestamp
